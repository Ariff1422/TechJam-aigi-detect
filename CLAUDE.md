# Project instructions

This is a TikTok TechJam 2026 hackathon project (Track 5: Robust AI-Generated Image Detection).

- **Read `PLAN.md` in full before doing any work in this repo.** It is the source of truth — architecture, dataset, augmentation strategy, phase-by-phase implementation order, and acceptance criteria are all specified there with evidence behind each decision.
- Follow `PLAN.md` section by section, in order. Don't skip a phase's acceptance criteria to move faster — they exist to catch bugs while they're cheap.
- Update the **Changelog & Decision Log** at the top of `PLAN.md` after every phase, every real result (a training run, an ablation, a robustness sweep), and any decision that changes or deviates from the plan. Write 2–4 sentences of report-ready prose, not a checkbox — this log gets edited down into the final written submission.
- If something in `PLAN.md` turns out to be wrong once you're working with real data or real results, fix it there and log the correction — don't silently work around it in code.
- Never commit secrets, API keys, or the raw downloaded dataset to this repo.
